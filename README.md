# Improved Fullscreen

Play RuneLite in fullscreen. Choose **Borderless** (default), **Exclusive**, or **Windowed**, and pick your monitor in the plugin settings.

Fullscreen on startup is on by default. Set a hotkey or use the sidebar button to toggle fullscreen. If prompted about custom window chrome, follow the instructions and restart RuneLite, or cancel to stay windowed.

Maintained by [Endrit](https://github.com/Endrit-alt/fullscreen). Based on the original Fullscreen plugin by [dekvall](https://github.com/dekvall). Original copyright notices and the [BSD 2-Clause license](LICENSE) are preserved.
